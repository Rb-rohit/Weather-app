# 🌦️ Weather Application

A simple and responsive **Weather Application** that allows users to search for any city and get real-time weather information such as temperature, weather conditions, and more.

## 🚀 Features

- 🔍 Search weather by city name
- 🌡️ Displays real-time temperature
- ☁️ Shows weather condition (Cloudy, Rainy, Sunny, etc.)
- 📱 Responsive user interface
- ⚠️ Error handling for invalid city names

## 🛠️ Tech Stack


- **JavaScript**

- **HTML5**
- **CSS3**
- **Weather API**
